# Поиск общих ключевых точек на изображениях

Реализация домашнего задания по поиску и сопоставлению локальных особенностей планктона.

## Описание решения:
В качестве основного алгоритма выбран **SIFT**. Для корректного сопоставления дескрипторов было выполнено предварительное зеркальное выравнивание изображений к левой ориентации. Сопоставление производилось методом взаимного поиска, а фильтрация ТОП-30 лучших точек выполнялась на основе минимального суммарного Евклидова расстояния.

## Результаты:
* Найдено сквозных общих точек: 110
* Отображено лучших точек: 30
